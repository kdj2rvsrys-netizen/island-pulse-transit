# Island Pulse UI Demo 原型

這是 Phase 0 的本機互動式 UI 原型，使用單一 HTML/CSS/JavaScript 檔案，沒有外部套件、正式 App 框架或後端。

## 啟動

在此資料夾開啟終端機：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

然後瀏覽 `http://127.0.0.1:4173`。停止時在終端機按 `Ctrl+C`。

## 可操作內容

- 點地圖事件標記或事件列表，查看同一筆事件詳情。
- 切換事故、施工、封路、壅塞和測速照相圖層；可全部顯示。
- 右上方「Demo 狀態」可切換資料已更新、載入中、無資料、資料過期及連線錯誤；錯誤/無資料狀態可重試。
- 手機寬度可點抽屜把手或上下滑動切換收合、半展開和完整清單；事件詳情以抽屜卡片顯示。
- 可切換淺色/深色示意、測試導覽焦點和搜尋提示。

## 資料與功能界線

畫面內所有道路、地點、事件、時間與來源都是假資料，均標示為 Demo。底圖是為原型繪製的示意路網，非真實地圖資料。原型不使用 GPS、不發出提醒、不連接任何交通 API；測速照相標記也只是視覺展示。
